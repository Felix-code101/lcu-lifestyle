# Liids University (LU) - Campus Life 3D 🎓🇳🇬

An immersive 3D isometric campus life simulation game and student roleplay universe set at **Liids University (LU), Ibadan**.

## 🌟 Key Features

- **🏛️ High-Detail 3D Campus Architecture**:
  - Senate Building & Clock Tower, Main University Gate, Central Library, Faculty of Law, Computer Science Tech Hub, Central Cafeteria, and more.
- **🚶 Dynamic Campus Transit**:
  - Trekking (Fitness XP + Stamina drain) vs. Keke Napep (₦250 fast transit).
- **🏢 Dedicated 3D Scenes**:
  - **Hostel Living Space**: Customizable dorm room with procedural furniture, desk notes, wardrobe, and cooler.
  - **Lions Hall**: Event center for SUG Freshers Night, Department Dinners, and Hall Bashes.
  - **Adeline Hall**: DJ Spin Booth with Web Audio synthesizer for Amapiano and Afrobeats.
  - **LU Sports Arena**: 1v1 Penalty Shootout against varsity keeper Tobi + Campus Bet Booking Terminal.
  - **LU Medical Centre**: Triage clinic for exhaustion recovery and glucose drips.
  - **Guesthouse**: Luxury lodging for soft life rejuvenation.
  - **Spiritual Centres**: Campus Chapel & Central Mosque with Faith progression tracks.
- **🗳️ Campus Politics & Hustles**:
  - SUG Presidential Election campaigns, student hustles (Small Chops vendor, freelance projects), and exam malpractice tribunal.
- **⚡ Real-Time Multiplayer**:
  - Presence synchronization across browser tabs and local network via BroadcastChannel / Supabase Realtime.
  - Matriculation onboarding with 15% Nepo Baby / 85% Lapo Hustler background roll.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **3D Engine**: Three.js + OrbitControls
- **Styling**: Tailwind CSS (strict light/white modern aesthetic)
- **Icons**: Lucide React
- **Audio**: Web Audio API Procedural Synth
- **Multiplayer**: Supabase Realtime + Web BroadcastChannel

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/Felix-code101/LU-Lifestyle.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
